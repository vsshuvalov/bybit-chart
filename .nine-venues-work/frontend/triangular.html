Проверка треугольных циклов

Три обмена. Одна биржа. Один замкнутый маршрут.

Сканер ищет путь A → B → C → A среди 50 ликвидных тикеров каждой площадки, учитывает три taker-комиссии, доступный объём top-of-book и risk buffer. Реальных ордеров и приватных API нет.
